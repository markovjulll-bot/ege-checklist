# Чек-лист ЕГЭ по русскому для Netlify

Ученики отмечают прогресс без регистрации, учитель видит отметки всего класса.

- `https://ВАШ-САЙТ.netlify.app/` — страница ученика
- `https://ВАШ-САЙТ.netlify.app/teacher.html` — таблица класса, вход по паролю

Отметки хранятся в Netlify Blobs — встроенном хранилище Netlify, отдельная база не нужна.

## Как выложить

Простое перетаскивание папки в Netlify Drop не подойдёт: без сборки не заработает серверная функция, и отметки не будут сохраняться. Используйте один из двух способов.

### Способ 1. Через GitHub

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В Netlify выберите **Add new site → Import an existing project → GitHub** и укажите репозиторий. Настройки сборки подтянутся из `netlify.toml`.
3. Задайте пароль учителя (см. ниже) и запустите **Deploy** ещё раз.

### Способ 2. Из терминала на Mac

```bash
cd ege-checklist-netlify
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

При первом запуске CLI спросит, создать новый сайт или привязать существующий.

## Пароль учителя

В Netlify откройте **Site configuration → Environment variables** и добавьте переменную `TEACHER_PIN` со своим паролем. После этого сделайте повторный деплой (**Deploys → Trigger deploy**). Без этой переменной таблица класса не откроется.

## Как пользуются ученики

1. Открывают ссылку, вписывают имя и отмечают пункты. Всё сохраняется автоматически.
2. Каждому выдаётся код из 8 символов. С ним можно продолжить на другом устройстве: кнопка «У меня уже есть код».

## Карточки к заданиям 9–15

Экспортируйте карточки в PDF, положите файл в папку `public` (например, `public/cards.pdf`) и впишите путь в начале `public/tasks.js`: `const CARDS = "/cards.pdf";`. После этого у заданий 9–15 появится ссылка на карточку.

## Если поменяете пункты чек-листа

Число пунктов в каждом задании записано в двух местах: `public/tasks.js` и массив `ITEMS` в `netlify/functions/progress.mjs`. Если добавляете или убираете пункты, поправьте оба места.
